# Taropeuta: Booking & Payments Platform (Case Study)

A production booking and payments platform I designed, built and run for my own consultancy, Taropeuta, an online astrology and tarot service with clients across multiple time zones.

> The source code is private because it runs a live business. This repository documents what the platform does, how it is built and my role in it.

## What it does

- **Online booking** of sessions for clients in different time zones
- **Card payments with Stripe**
- **No double bookings**: a database constraint prevents the same slot from being booked twice
- **Secure client data** with row-level security in PostgreSQL
- **Bilingual experience** in English and Portuguese

## Tech stack

| Layer | Technology |
| --- | --- |
| Front-end | Next.js, TypeScript |
| Database & auth | Supabase (PostgreSQL) |
| Payments | Stripe |
| Hosting | Vercel |

## My role

I did it end to end: database design, front-end, payment integration, deployment and ongoing support. I also handle every user issue myself (access, payments, scheduling, video calls) in English, Portuguese and Spanish.
